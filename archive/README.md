# Archive

Thư mục này không phải bài lab.

- `spark-lab/`: code và notebook đi kèm sách *Spark: The Definitive Guide*, kèm notebook bên ngoài và PDF. Code sách theo Apache License 2.0 (`license.md`). PDF sách không dùng làm bài tập.
- `hadoop_lab/`: PDF Hortonworks/HDP sandbox. HDP đã hết vòng đời.
- `hangout/`: slide buổi học.
- `tips/`: bài viết và tài liệu Spark đã lưu.

Lộ trình làm bài nằm ở README gốc và `platform/docker-compose.yml`.
